# 周报撰写指南

## 结构模板（必须遵守）

1. **本周结论**（≤2 句）：最重要的进展或风险，先说结论
2. **关键进展**（3-5 条）：每条 = 做了什么 + 结果/数据，不写过程
3. **风险与阻塞**（0-3 条）：每条附带需要的支持
4. **下周计划**（≤3 条）：可验证的目标，不写"继续推进"

## 语言风格

- 用数据说话："完成 80%"优于"基本完成"
- 每条以动词开头，删除"进行""开展"等冗词
- 面向读者写：管理者看结论，协作者看细节

## 常见错误（写完对照检查）

- 把流水账当进展（没有结果导向）
- 风险写得含糊（"有一定风险"——什么风险？需要谁做什么？）
- 下周计划不可验证（"继续优化"——优化到什么程度算完成？）
