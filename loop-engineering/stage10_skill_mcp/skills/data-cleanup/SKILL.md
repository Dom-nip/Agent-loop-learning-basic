# 数据清洗指南

## 处理顺序（必须按此顺序）

1. **探查**：先统计行数、字段类型、缺失比例，不要直接改
2. **去重**：整行重复直接删；键重复保留最新（按时间列判断）
3. **缺失值**：数值列填中位数、分类列填"unknown"、时间列报错人工确认
4. **标准化**：日期统一 `YYYY-MM-DD`；金额统一保留两位小数；名称去首尾空白
5. **校验输出**：清洗前后行数对比 + 每步改动统计

## 输出约定

- 清洗结果写 `workspace/cleaned/<原文件名>`，不要覆盖原始文件
- 同时产出 `workspace/cleaned/<原文件名>.report.md`：前后行数、每步改动、遗留问题

## 红线

- 不删有唯一键的行（哪怕看起来是脏数据——先报告）
- 不猜测业务含义（unit_price=0 是促销还是脏数据？报告，不擅自决定）
