## 这段记录里值得回看的四个瞬间

1. **主动 save_memory**：没有"记住"二字时（"补充一条"），模型依然判断这是
   长期事实并调用了工具——记忆分层的纪律已通过 description 注入行为。
2. **沙盒与分层的交界**：模型想写 notes/ 被拦——它分不清"工作笔记该写哪"，
   harness 用路径规则兜底。分层设计要让每层的入口可控。
3. **收尾筛选不是复读机**：第二次退出时它判定"没有新事实"——沉淀的质量
   体现在"不存什么"，而不只是"存了什么"。
4. **记忆即背景**：会话 2 的回答自然带着项目上下文，没有"根据我的记忆……"
   式的机械开场——记忆注入的位置（system prompt）决定了它被当成背景约束。
